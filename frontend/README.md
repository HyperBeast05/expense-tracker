# Frontend

This is the React + Vite frontend for Expense Tracker.

For complete project setup instructions, including MySQL schema setup, backend configuration, environment variables, and run commands, see the [project README](../README.md).

## Frontend commands

```bash
npm ci
npm run dev
```

Before running, copy `.env.example` to `.env` and set `VITE_API_URL` if the backend API is not available at `http://localhost:5000/api`.

Useful checks:

```bash
npm run lint
npm run build
```
